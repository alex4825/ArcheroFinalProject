# Base Blast Defense
### [Играйте онлайн на Itch.io](https://alex4825.itch.io/base-blast-defense)
## 🎮 Об игре

Base Blast Defense - это top-down аркада, где игрок защищает дом от волн врагов, используя взрывы кликами и защитные механизмы, такие как турели, мины и пламя, которые покупаются за золото. За алмазы покупаются улучшения в меню. Обе валюты даются после победы в уровне. Графика выполнена в простом, низкополигональном стиле.

## 🛠 Разработка

Игра разработана на Unity 2022 с применением следующих технологий:

*   самописный **DI Container**
*   самописная **ECS** система для контроля над сущностями в геймплее
*   иерархическая **State Machine** для ИИ сущностей и для состояний геймплея
*   самописная реализация **реактивности** (ReactiveVariable и ReactiveEvent)
*   **MVP** архитектура для элементов UI
*   **DOTween** для анимаций
*   асинхнонность на **Coroutine**
*   система сохранений с применением **NewtonSoft.Json**
*   оптимизация с использованием **FrameDebugger**: запечка окружения и света

В проекте упор на чистый год, гибкую и расширяемую архитектуру.
